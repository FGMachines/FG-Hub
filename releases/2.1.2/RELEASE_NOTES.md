# FG Link 2.1.2

إصدار FG Machines الرسمي، versionCode 47، موقّع بالمفتاح الأصلي ويُثبّت كتحديث مباشر دون حذف بيانات التطبيق.

- Direct VPS داخل قسم أجهزتي باستخدام حساب المستخدم الشخصي.
- استمرار LAN وZeroTier.
- معالج إعداد مشترك، مع فصل التهيئة عن اعتماد الأجهزة والصلاحيات.
- إعدادات تنبيهات البريد لحساب المستخدم.
- الريموت للتكييف والمراوح مستمر داخل FG Link.
- لا يتضمن تطبيق العملاء تسجيل دخول المالك.

تنبيهات البريد تحتاج إعداد SMTP على الخادم. التحكم بالأشعة تحت الحمراء يحتاج هاتفًا بمرسل IR وجهازًا متوافقًا.
