# Security

FG Link official releases are distributed by FG Machines.

## Release integrity

Each public APK release should include:

- Package ID: `com.fgmachines.rck`
- Version number
- SHA-256 checksum
- FG Machines publisher identification

Signing keys, passwords, API secrets, private build mappings and internal engineering material must never be committed to this public repository.

## Reporting

Security reports should be sent through an official FG Machines contact channel rather than posted publicly when they contain exploit details or sensitive information.
