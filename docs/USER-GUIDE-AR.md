# دليل استخدام FG Link — العربية

هذا الدليل مخصص للمستخدم النهائي لنسخة **FG Link 1.6.11** الرسمية.

## 1) تثبيت التطبيق
1. حمّل ملف APK الرسمي من صفحة Releases في هذا المستودع.
2. تحقّق من قيمة SHA-256 المنشورة مع الإصدار.
3. ثبّت التطبيق ثم افتحه وامنحه أذونات الشبكة والإشعارات المطلوبة.

> الصور الحقيقية من الإصدار النهائي ستوضع داخل `docs/images/` بعد اكتمال بناء APK النهائي، ولن نستخدم صورًا تجريبية أو Mockups.

## 2) إضافة مشترك MTTL-W01
1. افتح FG Link واختر **إضافة مشترك / Setup**.
2. ضع المشترك في وضع الإعداد حتى تظهر شبكة `TONLY_TAP_...` أو `ONLY_TAP_...`.
3. اتصل بشبكة إعداد المشترك عند طلب التطبيق.
4. اختر شبكة Wi‑Fi ‏2.4 GHz وأدخل كلمة المرور.
5. أكمل الإعداد حتى تظهر حالة المشترك **Online** داخل FG Link.
6. افتح **أجهزتي** وغيّر الاسم/الغرفة إن رغبت.

## 3) التحكم المحلي
FG Link يعمل محليًا بدون خادم خارجي. الهاتف المسيطر يبقى على نفس الشبكة المحلية ويستقبل اتصال المشترك، ثم يعرض المخارج الأربعة وحالتها والطاقة والبيانات المتاحة.

## 4) إضافة ZeroTier للتحكم البعيد
1. ثبّت ZeroTier على الهاتف المسيطر والهاتف البعيد أو على الراوتر الذي سيعمل كبوابة.
2. انضم بالجهازين إلى نفس شبكة ZeroTier الخاصة بك.
3. داخل FG Link افتح **Remote / التحكم البعيد**.
4. اختر مسار ZeroTier.
5. أدخل عنوان ZeroTier الخاص بالهاتف المسيطر أو البوابة.
6. أنشئ Device Share Code أو Token محدود الصلاحيات من الهاتف المسيطر.
7. استورد الكود في الهاتف البعيد واختبر الوصول قبل مغادرة الشبكة المحلية.

**مهم:** لا تفتح TCP 18086 مباشرة على الإنترنت العام. استخدم LAN/VPN أو HTTPS عندما يتم تشغيل خادم FG Link لاحقًا.

## 5) Home Assistant
من **Smart Home** أنشئ Token خاصًا بـHome Assistant ثم استخدم عنوان FG Link المحلي/الخاص. يمكن بعد ذلك تمرير الكيانات إلى Alexa أو Google Home من خلال Home Assistant.

## 6) ربط التطبيق بخادم FG Link VPS
1. افتح قسم **FG Link VPS** داخل التطبيق.
2. انسخ **بصمة الهاتف** ذات 64 خانة من الزر المخصص.
3. أرسل البصمة إلى إدارة FG Link.
4. بعد إنشاء API مرتبط بالبصمة، أدخل عنوان HTTPS للخادم وAPI في التطبيق.
5. فعّل مزامنة VPS.
6. ستظهر المشتركات المرتبطة بالهاتف داخل لوحة الخادم مع حالة Online/Offline.
7. يمكن للإدارة تشغيل أو إيقاف كل مخرج من المخارج الأربعة من لوحة VPS؛ التنفيذ نفسه يتم على الهاتف المتصل بالمشترك.

إذا تغير الهاتف، يلزم إدخال بصمة الهاتف الجديد من لوحة الإدارة وإنشاء API جديد. API القديم يُلغى عند عملية النقل.

## المساعدة
استخدم فقط ملفات الإصدار الرسمية المنشورة بواسطة **FG Machines** ولا تثبّت نسخًا معاد توقيعها من مصادر أخرى.
