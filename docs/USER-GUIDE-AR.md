# دليل استخدام FG Link 1.6.13 — العربية

هذا الدليل يشرح الاستخدام الكامل للنسخة الرسمية **FG Link 1.6.13 Build 42** المنشورة بواسطة **FG Machines**.

## المتطلبات

- Android 8.0 أو أحدث.
- مشترك/وحدة MTTL-W01 متوافقة مع FG Link.
- شبكة Wi-Fi ‏2.4 GHz أثناء الإعداد المحلي.
- اتصال إنترنت إذا أردت استخدام خادم FG Link VPS.
- لا يحتاج العميل إلى إنشاء بريد إلكتروني أو كلمة مرور داخل التطبيق.

## 1) تثبيت التطبيق لأول مرة

1. حمّل ملف APK الرسمي.
2. اسمح بتثبيت التطبيقات من المصدر الذي استخدمته للتحميل إذا طلب Android ذلك.
3. ثبّت FG Link وافتحه.
4. اسمح بأذونات الشبكة والإشعارات اللازمة عندما يطلبها التطبيق.
5. لا تحتاج إلى تسجيل حساب مستخدم.

## 2) إضافة مشترك MTTL-W01

1. افتح FG Link.
2. اختر **إضافة مشترك / Setup**.
3. ضع MTTL-W01 في وضع الإعداد حتى تظهر شبكة الإعداد مثل TONLY_TAP_... أو ONLY_TAP_....
4. اتصل بشبكة إعداد المشترك عند طلب التطبيق.
5. اختر شبكة Wi-Fi ‏2.4 GHz المطلوبة.
6. أدخل كلمة مرور Wi-Fi.
7. أكمل الإعداد حتى يظهر المشترك Online داخل FG Link.
8. من **أجهزتي** يمكنك تغيير اسم المشترك أو الغرفة.

## 3) التحكم المحلي

التشغيل المحلي لا يعتمد على الخادم الخارجي. عندما يكون الهاتف والمشترك في نفس بيئة الشبكة يستطيع FG Link عرض المشترك المتصل، التحكم في المخارج الأربعة، عرض حالة كل مخرج، وعرض بيانات الطاقة والحالة التي يرسلها المشترك.

## 4) بصمة الهاتف

لكل تثبيت رسمي من FG Link بصمة هاتف Privacy-Reduced بطول 64 خانة Hex.

1. افتح قسم **FG Link VPS**.
2. ستظهر بصمة الهاتف تلقائيًا.
3. اضغط **نسخ بصمة الهاتف**.
4. أرسل البصمة إلى إدارة FG Machines.
5. الإدارة تنشئ API مرتبطًا بهذه البصمة.

البصمة هي معرّف الهاتف داخل نظام FG Link، ولا يحتاج العميل إلى كتابة اسمه في الخادم.

## 5) ربط التطبيق بخادم FG Link VPS

عنوان الخادم الرسمي ثابت داخل التطبيق:

https://link.fgmachines.org

العميل **لا يكتب عنوان الخادم**.

بعد أن تستلم API من الإدارة:

1. افتح قسم **FG Link VPS**.
2. الصق الـAPI في الحقل المخصص.
3. اضغط **ربط VPS**.
4. عند نجاح الربط يتم تفعيل مزامنة الحالة.
5. يبدأ التطبيق بإرسال حالة الهاتف والمشتركات والمخارج إلى الخادم عبر HTTPS.

إذا حاول API العمل مع بصمة هاتف مختلفة يرفض الخادم الربط.

## 6) التحكم من لوحة الخادم

1. الخادم يعرض الهاتف المرتبط بالبصمة.
2. تظهر المشتركات التي يزامنها الهاتف.
3. يظهر لكل مشترك أربعة مخارج.
4. لكل مخرج زر واحد فقط:
   - أخضر = متصل / ON.
   - أحمر = مغلق / OFF.
   - كهرماني = جارٍ تنفيذ الأمر.
   - رمادي = الحالة غير معروفة بعد.
5. الضغط على الزر يرسل الحالة العكسية.
6. الهاتف يستقبل الأمر عبر HTTPS.
7. الهاتف ينفذ الأمر محليًا على MTTL-W01.
8. التطبيق يرسل نتيجة التنفيذ مرة أخرى للخادم.

الخادم لا يتصل بالمشترك مباشرة ولا يحتاج إلى فتح منفذ وارد على هاتف العميل.

## 7) تغيير الهاتف

1. ثبّت FG Link على الهاتف الجديد.
2. انسخ بصمة الهاتف الجديدة.
3. أرسلها إلى الإدارة.
4. الإدارة تعيد ربط الحساب بالبصمة الجديدة وتصدر API جديدًا.
5. API القديم يُلغى عند النقل.

## 8) ZeroTier والتحكم البعيد الخاص

FG Link يحتفظ بمسار LAN/ZeroTier منفصل عن VPS. يمكن استخدام ZeroTier للتحكم الخاص بين الأجهزة بدون الاعتماد على خادم FG Link.

مهم:
- لا تفتح TCP 18086 على الإنترنت العام.
- استخدم LAN أو VPN/ZeroTier للمسارات المحلية.
- خادم FG Link العام يستخدم HTTPS.
- إعدادات VPS API منفصلة عن إعدادات LAN/ZeroTier في 1.6.13.

## 9) Home Assistant

يمكن إنشاء Token محلي خاص بـHome Assistant من داخل FG Link وربطه بعنوان FG Link المحلي أو الخاص، ثم تمرير الكيانات إلى Alexa أو Google Home عبر Home Assistant حسب إعدادك.

## 10) معنى الحالات

- Online للهاتف: الهاتف أرسل Heartbeat حديثًا إلى VPS.
- Online للمشترك: الهاتف يرى MTTL-W01 متصلًا محليًا.
- حالة المخرج معروفة: التطبيق استلم حالة فعلية أو Telemetry موثوقة للمخرج.
- غير معروف: لم تصل بعد حالة مؤكدة، ولا تعني ON أو OFF.

## 11) إذا ظهر المشترك Online لكن المخارج «غير معروف»

1. تأكد أنك تستخدم Android 1.6.13 Build 42 أو أحدث.
2. تأكد أن المشترك متصل فعليًا بالهاتف.
3. افتح التحكم المحلي وتأكد أن حالة المخارج تظهر.
4. تأكد أن مزامنة VPS مفعلة.
5. انتظر دورة المزامنة التالية.
6. إذا استمرت الحالة، أعد تشغيل خدمة التحكم أو التطبيق ثم أعد فحص اللوحة.

## 12) إذا لم يتصل VPS

- تأكد من أن الـAPI منسوخ بدون مسافات إضافية.
- تأكد من وجود إنترنت على الهاتف.
- تأكد أن الـAPI أُنشئ لنفس بصمة الهاتف الحالية.
- لا تحتاج إلى تعديل عنوان الخادم لأنه ثابت داخل التطبيق.
- لا تستخدم API مخصصًا لهاتف آخر.

## 13) الأمان والخصوصية

الخادم لا يحتاج إلى تخزين كلمات مرور Wi-Fi، أسرار ZeroTier، MAC الخام للمشترك، مفاتيح توقيع APK، أو مفاتيح Android Keystore الخاصة.

التطبيق يستخدم HTTPS مع الخادم الرسمي، ويستخدم مرجعًا عشوائيًا Opaque للمشترك عند مزامنته مع VPS بدل إرسال MAC الخام.
