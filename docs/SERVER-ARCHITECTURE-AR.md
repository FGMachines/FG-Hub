# FG Link — بنية الخادم 1.6.12

الخادم أصبح جزءًا فعّالًا من منظومة FG Link مع بقاء التحكم المحلي هو طبقة التنفيذ الفعلية.

## دورة العميل

1. يثبت العميل تطبيق FG Link.
2. التطبيق يستخرج بصمة هاتف Privacy-Reduced بطول 64 خانة ويعرض زر نسخ.
3. يرسل العميل البصمة إلى إدارة FG Link.
4. تُدخل الإدارة البصمة في لوحة VPS؛ لا حاجة لاسم عميل.
5. الخادم ينشئ API Token عالي العشوائية مربوطًا مسبقًا بهذه البصمة.
6. العميل يدخل عنوان VPS وAPI في التطبيق.
7. أي اتصال ببصمة مختلفة يُرفض.

## التحكم في المشتركات

- الهاتف يزامن قائمة مشتركات MTTL-W01 وحالتها Online/Offline مع VPS.
- لا يرسل التطبيق MAC الخام إلى VPS؛ لكل مشترك مرجع عشوائي Opaque محفوظ محليًا.
- يرسل التطبيق أيضًا الحالة الفعلية المعروفة لكل مخرج إلى VPS.
- تعرض لوحة الإدارة زرًا واحدًا لكل مخرج: أخضر = متصل، أحمر = مغلق، كهرماني = الأمر قيد التنفيذ، رمادي = الحالة غير معروفة.
- الضغط على الزر يرسل الحالة العكسية مباشرة دون نافذة تنبيه متصفح مزعجة.
- الأمر يصل إلى التطبيق عبر اتصال HTTPS صادر من الهاتف.
- الهاتف لا ينفذ الأمر إلا إذا كان المشترك معروفًا ومتصلاً محليًا.
- التنفيذ يتم محليًا من الهاتف إلى MTTL-W01، ثم يرسل التطبيق نتيجة التنفيذ إلى الخادم.
- الأوامر غير المؤكدة يعاد تسليمها فقط حتى انتهاء TTL المحدد.

## الحدود الأمنية

الخادم لا يخزن:
- كلمات مرور Wi-Fi.
- أسرار ZeroTier.
- MAC الخام للمشترك.
- مفاتيح توقيع APK.
- مفاتيح Android Keystore الخاصة.

الخادم يحتفظ ببصمة الهاتف المخفّضة التي أرسلها التطبيق كمعرّف إداري، وHMAC داخلي لها للتحقق، وHashes للـAPI، ومراجع عشوائية للمشتركات، وحالة الاتصال وسجل الأوامر.

## النشر

المنصة تستهدف Ubuntu 24.04 / Debian 12 وتستخدم:
- Docker Compose
- Caddy HTTPS
- FastAPI
- PostgreSQL داخل شبكة Docker خاصة

ملفات إصدار الخادم الحالي موجودة في:

`server/1.6.12/`

ويتم التثبيت/الترقية بواسطة:

`sudo bash install-fg-link-vps.sh`

يحافظ المثبت على ملف `.env` والبيانات الحالية عند الترقية.
