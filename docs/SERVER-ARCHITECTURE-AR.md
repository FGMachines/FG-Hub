# FG Link — بنية الخادم الاختياري

الخادم مخطط له كطبقة **Relay اختيارية** وليس كمصدر الثقة الرئيسي للتحكم الكهربائي.

## الهدف الأمني
حتى في حالة اختراق لوحة الإدارة أو قاعدة بيانات الخادم، لا يجب أن يحصل المهاجم تلقائيًا على مفاتيح Wi‑Fi أو مفاتيح Android Keystore أو صلاحية مباشرة لتنفيذ أوامر على MTTL-W01.

المعلومات الحساسة التي تبقى على أجهزة المستخدم:
- مفاتيح التوقيع الخاصة.
- بيانات Wi‑Fi المحلية.
- تفاصيل الاتصال المحلي بالمشترك.
- مفاتيح/أسرار ZeroTier.
- مفاتيح توقيع APK.

الخادم يحتفظ فقط بالحد الأدنى التشغيلي المطلوب مثل معرّفات عشوائية، بصمات مفاتيح عامة، hashes لرموز عالية العشوائية، حالة online/offline وبيانات relay الضرورية.

## حدود الضمان
لا يوجد خادم يمكن اعتباره "لا يكشف شيئًا" حرفيًا عند الاختراق. التصميم يقلل أثر الاختراق: قد تُكشف metadata وحالة الاتصال أو يحدث تعطيل للخدمة، لكن مفاتيح التحكم الخاصة لا تُخزن على الخادم.

## التشغيل المستقبلي
- Ubuntu 24.04 / Debian 12
- Docker Compose
- Caddy HTTPS
- FastAPI
- PostgreSQL خاص داخل Docker network
- لا يتم نشر TCP 10086 أو TCP 18086 مباشرة على الإنترنت.

## التطبيق
نسخة Android تبقى Local-First. إعداد الخادم يكون Disabled افتراضيًا، وعند شراء VPS لاحقًا يكفي إدخال HTTPS endpoint وبيانات الربط من صفحة الإعدادات المخصصة بدون تغيير مسار التحكم المحلي.
